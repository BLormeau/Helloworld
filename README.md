# Helloworld

1er usage

## Petit guide de Visual Studio Code

### Ouvrir le projet

1. Ouvrir Visual Studio Code.
2. Aller dans **Fichier > Ouvrir le dossier...**.
3. Selectionner le dossier du projet.

### Utiliser l'interface

- **Explorateur** : parcourir et ouvrir les fichiers.
- **Recherche** : rechercher un mot dans tout le projet.
- **Extensions** : ajouter le support d'un langage ou d'un outil.
- **Terminal integre** : ouvrir un terminal avec **Ctrl + `**.

### Travailler efficacement

- Enregistrer : **Ctrl + S**
- Rechercher dans le fichier : **Ctrl + F**
- Ouvrir rapidement un fichier : **Ctrl + P**
- Afficher la palette de commandes : **Ctrl + Shift + P**
- Formater le document : **Shift + Alt + F**

### Lancer le projet

Ouvrir le terminal integre, puis executer les commandes indiquees dans la documentation du projet. Les extensions recommandees peuvent proposer un bouton **Run** ou **Debug** pour lancer le code directement.
